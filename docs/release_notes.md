# Release notes

## v1.2.1 (2026-11-08)

- Citation corrected: the paper describing the study is in preparation and has not been submitted. Cite the archived
  release on Zenodo (doi:10.5281/zenodo.24037833, all versions). `CITATION.cff` no longer names a journal article.

## v1.2.0 (2026-11-08)

- Documentation built with Sphinx: installation, tutorial, configuration and run settings, run set, model
  description, workflow rules, outputs, data sources, limitations.
- Tests (`tests/`): consistency of the run set, Monte Carlo samples, and a Snakemake dry run of all 289 runs.
- Continuous integration (GitHub Actions): linting with ruff and snakefmt, tests, documentation build.
- Issue and pull-request templates, contribution guidelines, pre-commit hooks, `Makefile`.
- `workflow/envs/environment.fixed.yaml` with the exact versions of the environment used for the archived results.
- Removed unused imports and variables in the scripts; results are unchanged.

## v1.1.1 (2026-11-07)

- The results summary is a workflow rule (`make_summary`): figures, tables and `key_indicators.csv`, the table of
  all reported indicators.
- README section on outputs and run names.

## v1.1.0 (2026-11-07)

- Snakemake workflow in the layout of PyPSA-USA: `workflow/` with `Snakefile`, `config/`, `envs/`, `rules/`,
  `scripts/` and `repo_data/`.
- The run set is a module (`scripts/run_set.py`) used by the workflow; any run can be requested as a target, and its
  dependencies are solved first.
- Monte Carlo samples generated by `scripts/mc_samples.py`.
- The 2024 benchmark runs of the 30-region model are part of the run set (289 runs).

## v1.0.0 (2026-11-07)

- First release: code of the study comparing the revised PDP8 with a least-cost system for 2035 and 2040, with the
  processed inputs and all model runs archived on Zenodo.
