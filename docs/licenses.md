## Data

The processed inputs and results on [Zenodo](https://doi.org/10.5281/zenodo.24037834) are derived from datasets with
their own licences. The main ones are:

| Data | Licence |
|---|---|
| OpenStreetMap | ODbL 1.0 |
| Global Energy Monitor trackers | CC BY 4.0 |
| ERA5 (Copernicus Climate Change Service) | Copernicus licence |
| ESA WorldCover, Copernicus DEM | CC BY 4.0, Copernicus DEM licence |
| WDPA | terms of use of UNEP-WCMC (non-commercial) |
| Global Wind Atlas | CC BY 4.0 |
| Ember | CC BY 4.0 |
| World Bank energydata.info | CC BY 4.0 |
| GADM | free for academic and non-commercial use, no redistribution (not included) |

The full list, with the licence of every dataset, is in [data sources](data_sources.md). Users of the data must
respect these licences and cite the original sources.
